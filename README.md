# Airline Reservation and Ticket Booking System

A full-stack **Airline Reservation and Ticket Booking System** developed using **Java, JSP, Servlets, JDBC, MySQL, HTML5, CSS3, and Bootstrap 5**, following the **MVC architecture**.

### Key Features

* User and Admin authentication with role-based access control
* Session management and password recovery
* Admin flight management with **CRUD operations**
* Flight search and availability checking
* Online ticket booking and cancellation
* Booking history and seat availability management
* JDBC-based MySQL database integration
* Server-side input validation and SQL query optimization
* Responsive user interface using Bootstrap 5

### Technologies

**Java | JSP | Servlets | JDBC | MySQL | HTML5 | CSS3 | Bootstrap 5 | Apache Tomcat | MVC**
